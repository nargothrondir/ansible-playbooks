# ufw

[English](README.md) | **Русский**

## Описание

Host-файрвол для нод флота: входящий трафик запрещён по умолчанию, короткий
список публичных TCP-портов разрешён, а сервисные порты открыты **только на
интерфейсе NetBird-меша**.

Mesh-правило привязано к интерфейсу, а не к IP пира: mesh-адресами владеет
IPAM NetBird, и при миграции на self-host (#6) они пересоздадутся — вшитые в
правила IP протухли бы молча. *Кто* внутри меша может подключаться —
контролируют политики NetBird Access Control; host-файрвол отвечает только за
«только из меша» (эшелонированная защита, см. issue #49).

Правила применяются до включения файрвола, поэтому включение по SSH безопасно.
Заметка про Docker: опубликованные порты контейнеров обходят ufw — стек
remnanode работает в `network_mode: host`, так что нод флота это не касается.

## Переменные

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `ufw_public_tcp` | `[{port: 22, comment: SSH}, {port: 443, comment: HTTPS}]` | TCP-порты, доступные отовсюду; `comment` виден в `ufw status` |
| `ufw_mesh_tcp` | `[{port: 2222, …}, {port: automation_ssh_port, …}, {port: 22022, …}]` | TCP-порты, доступные только с mesh-интерфейса. 22022 — точка входа NB-SSH; сам NetBird его не открывает |
| `ufw_mesh_interface` | `wt0` | Имя интерфейса NetBird (WireGuard) |

## Зависимости

Нет (модуль `ufw` из коллекции `community.general`).

## Пример

```yaml
- hosts: fleet
  become: true
  roles:
    - ufw
```

## Поддерживаемые ОС

Debian 12/13, Ubuntu 24.04.
