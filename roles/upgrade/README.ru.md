# Роль: upgrade

[🇬🇧 English](README.md) · 🇷🇺 Русский

## Описание

Обновляет кэш apt, обновляет установленные пакеты, удаляет устаревшие и
перезагружает хост только если работающее ядро перестало быть новейшим из
установленных. Эквивалент команды:

```bash
apt update && apt full-upgrade -y && apt autoremove --purge -y
```

Роль идемпотентна: если обновлять нечего, изменений не вносится и
перезагрузка не выполняется.

**Как принимается решение о перезагрузке.** `/var/run/reboot-required` — это
соглашение *Ubuntu*: создающий его хук лежит в `update-notifier-common`, а
минимальный Debian этот пакет не ставит и не тянет. Опора на один этот маркер
делала проверку вечно ложной на хостах Debian — прогон мог обновить ядро, glibc
и systemd и всё равно пропустить перезагрузку. Поэтому роль ставит
`needrestart` и читает `NEEDRESTART-KSTA` из его пакетного вывода (`2` — ждёт
ABI-совместимое обновление, `3` — ждёт смена версии); маркер по-прежнему
учитывается там, где он есть. `needrestart` переведён в режим «только список»,
чтобы его apt-хук не мог задать вопрос посреди прогона Ansible.

## Переменные

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `upgrade_apt_type` | `dist` | Стратегия apt (`dist` = full-upgrade; `safe` = без удалений) |
| `upgrade_autoremove` | `true` | Удалять более не нужные пакеты |
| `upgrade_autoremove_purge` | `true` | Очищать конфиги при автоудалении |
| `upgrade_cache_valid_time` | `3600` | Сколько секунд кэш apt считается свежим |
| `upgrade_reboot` | `true` | Автоматически перезагружать при необходимости |
| `upgrade_reboot_timeout` | `600` | Сколько секунд ждать возврата хоста после перезагрузки |

## Зависимости

Нет. Требует повышения привилегий (`become: true`) на целевом хосте.

## Пример

```yaml
- name: Update and upgrade servers
  hosts: new_vps
  become: true
  gather_facts: true
  vars:
    ansible_user: ansible
    ansible_ssh_private_key_file: "~/.ssh/ansible_ed25519"
  roles:
    - role: upgrade
```

## Поддерживаемые ОС

Debian (bookworm, trixie), Ubuntu (jammy, noble).
