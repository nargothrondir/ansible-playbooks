# Роль: xanmod

[🇬🇧 English](README.md) · 🇷🇺 Русский

## Описание

Устанавливает производительное ядро [XanMod](https://xanmod.org/) из
официального APT-репозитория XanMod (ключ подписи →
`/etc/apt/keyrings/xanmod.asc`, deb822-источник →
`/etc/apt/sources.list.d/xanmod.sources`). Идемпотентна.

**Требуется перезагрузка**, чтобы загрузиться в новое ядро; роль сама НЕ
перезагружает. Активирует его роль `upgrade`, когда обнаружит,
что работающее ядро перестало быть новейшим установленным (или ручная
перезагрузка).

Замечание: `deb.xanmod.org` — сторонний зеркальный домен и в некоторых регионах
периодически блокируется (см. issue #3 для ноды `ru`).

## Переменные

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `xanmod_variant` | `x64v3` | Уровень CPU/PSABI: `x64v1`/`x64v2`/`x64v3`. Определить — скриптом XanMod `check_x86-64_psabi.sh` |
| `xanmod_package` | `linux-xanmod-{{ xanmod_variant }}` | Устанавливаемый пакет |
| `xanmod_apt_arch` | `amd64` | Архитектура APT-репозитория |
| `xanmod_reboot` | `false` | Перезагрузка в новое ядро, если оно только что установлено (handler) |

## Зависимости

Нет.

## Пример

```yaml
- hosts: managed
  become: true
  roles:
    - role: xanmod
```

## Поддерживаемые ОС

Debian 12/13, Ubuntu 24.04 (`os_family == 'Debian'`), x86-64.
