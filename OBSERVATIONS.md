# Observations Log

Real-world log of agent behaviour during working sessions.
Each entry documents a failure mode, unexpected behaviour, or noteworthy pattern.
Entries drive future revisions of `CLAUDE.md` and the skill.

---

## How to Log

```
## YYYY-MM-DD — <short title>

**Task:** what was asked
**Rule:** which §section applies
**Observed:** what the agent actually did
**Expected:** what it should have done
**Frequency:** first occurrence / repeated (N times)
**Action:** [pending | added to ROADMAP | fixed in CLAUDE.md vX.Y]
```

Frequency matters: a single occurrence may be noise.
Three or more occurrences of the same pattern = candidate for a rule change.
